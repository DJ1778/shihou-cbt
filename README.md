# 司法試験 CBT 演習（論文式）ウェブサイト版

ログインなしで使える、司法試験CBT方式の論文式演習サイトです。

## 入っているもの

- `index.html` … サイト本体
- `laws/` … 試験用法文（e-Gov法令検索のデータ、本則のみ）
- `criteria.json` … 評価基準・出題趣旨・採点実感の要約（自己採点の画面で表示）
- `cmaps.json` … 日本語PDFを読むためのデータ

フォルダの構成は変えずに、全部まとめて置いてください。

## 公開のしかた（どちらか一つ）

### A. Netlify Drop（いちばん簡単・無料）

1. このzipを解凍します。
2. ブラウザで https://app.netlify.com/drop を開きます。
3. 解凍したフォルダを、画面の枠の中へドラッグ＆ドロップします。
4. 数秒で `https://○○○.netlify.app` のURLができます。これを共有すれば誰でも使えます。

URLを残したり、あとで中身を差し替えたりするときは、Netlifyの無料アカウントを作ってください。

### B. GitHub Pages（無料）

1. GitHubで新しいリポジトリを作ります（Public）。
2. 「Add file」→「Upload files」で、解凍したフォルダの中身を全部アップロードします。`index.html` がリポジトリの一番上に来るように置いてください。
3. 「Settings」→「Pages」→「Branch」を `main`、フォルダを `/ (root)` にして「Save」を押します。
4. 1〜2分で `https://ユーザー名.github.io/リポジトリ名/` が使えるようになります。

## 注意

- ファイルをダブルクリックして直接開くと、法文が読み込めません。上のどちらかの方法で公開してから使ってください。手元のパソコンだけで試したいときは、フォルダで `python3 -m http.server` を実行して `http://localhost:8000` を開いてください。
- 答案の記録は、使う人それぞれの端末のブラウザに保存されます。サイトを置いた人には見えません。別の端末に移すときは、「答案の記録」→「記録を書き出す」で保存したファイルを、移した先で「記録を読み込む」から読み込みます。
- 写真・PDFの文字読み取りは、使う人のブラウザの中で行います（無料）。初回だけ読み取り用データ（約数MB〜十数MB）を取得します。AIの採点はこの版にはありません。
- 法令は2026年11月時点の内容です。改正があっても自動では更新されません。
